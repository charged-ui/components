Slot a trigger bar into `slot="trigger"` and one panel per menu into
`slot="content"`. Triggers are matched to panels by `data-target` /
`data-id`, and the panel morphs between them — width, height, and slide
direction are all derived, so adding a menu means adding markup, nothing else.

The demo below reproduces a three-panel product nav. Panels are light DOM, so
their contents are styled by your own CSS, not the component's.

## API

| Attribute    | Type   | Default | Notes                                      |
| ------------ | ------ | ------- | ------------------------------------------ |
| `gutter`     | number | `16`    | Reflected — min gap from the viewport edge |
| `closeDelay` | number | `150`   | Hover-out delay in ms before closing       |

| Slot      | Purpose                                       |
| --------- | --------------------------------------------- |
| `trigger` | The nav bar; contains `[data-target]` buttons |
| `content` | One panel per menu, keyed by `data-id`        |

Each `slot="content"` element may declare its width with `data-width` (px);
without it the panel measures the element itself.
