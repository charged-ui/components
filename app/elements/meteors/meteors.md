# Meteors

An animated meteor shower background effect.

## Example

```html
<div class="relative overflow-hidden h-96">
  <ui-bg-meteors number="20"></ui-bg-meteors>
  <span>Your content here</span>
</div>
```

## Properties

| Property        | Type     | Default | Description                                  |
| --------------- | -------- | ------- | -------------------------------------------- |
| `number`        | `number` | `20`    | Number of meteors                            |
| `min-delay`     | `number` | `0.2`   | Minimum animation delay in seconds           |
| `max-delay`     | `number` | `1.2`   | Maximum animation delay in seconds           |
| `min-duration`  | `number` | `2`     | Minimum animation duration in seconds        |
| `max-duration`  | `number` | `10`    | Maximum animation duration in seconds        |
| `angle`         | `number` | `60`    | Angle of meteor travel in degrees            |
