# Aurora

An animated aurora background effect with an optional radial gradient mask.

## Example

```html
<ui-bg-aurora show-radial-gradient>
  <div>Your content here</div>
</ui-bg-aurora>
```

## Properties

| Property               | Type      | Default | Description                                 |
| ---------------------- | --------- | ------- | ------------------------------------------- |
| `show-radial-gradient` | `boolean` | `true`  | Apply a radial mask to fade the aurora edge |

## Dark Mode

The aurora adapts to dark mode automatically via `.dark .aurora-container` CSS rules. Add the `dark` class to a parent element.
